# 🚀 Dzakri Phalosa Nugroho - Portfolio

Modern, responsive, and professional portfolio website built with pure HTML, CSS, and JavaScript.

[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Live-success?logo=github)](https://kanekicraynet.github.io)
[![License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

## ✨ Features

- **Modern Design** - Glassmorphism effects, animated gradients, and smooth micro-interactions
- **Dark/Light Mode** - Toggle between themes with smooth transitions
- **Fully Responsive** - Optimized for mobile, tablet, and desktop devices
- **Scroll Animations** - Elements reveal on scroll with stagger effects
- **3D Tilt Effects** - Interactive project cards that respond to cursor movement
- **Typing Animation** - Dynamic text animation in hero section
- **SEO Optimized** - Proper meta tags, Open Graph, and semantic HTML

## 🛠️ Tech Stack

- **HTML5** - Semantic markup
- **CSS3** - Custom properties, Flexbox, Grid, animations
- **JavaScript (ES6+)** - Vanilla JS with modern features
- **Google Fonts** - Inter & Outfit typography

## 🚀 Getting Started

### Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/KanekiCraynet/kanekicraynet.github.io.git
   cd kanekicraynet.github.io
   ```

2. Start a local server:
   ```bash
   python3 -m http.server 8080
   # or
   npx serve .
   ```

3. Open in browser: `http://localhost:8080`

### Deployment

This site is automatically deployed via GitHub Pages. Simply push changes to the `main` branch:

```bash
git add .
git commit -m "Update portfolio"
git push origin main
```

## 🎨 Customization

### Colors

Edit `assets/css/variables.css` to change the color scheme:

```css
:root {
    --color-primary: #8b5cf6;      /* Purple */
    --color-secondary: #06b6d4;     /* Cyan */
    --color-accent: #f472b6;        /* Pink */
}
```

### Content

Update `index.html` to change:
- Personal information and bio
- Project details and links
- Skills and expertise
- Contact information
